Chân dung cá nhân

Tôi hiện là sinh viên năm 3 chuyên ngành Công nghệ thông tin với định hướng trở thành lập trình viên Web chuyên nghiệp.

Thuật ngữ chuyên môn

HTML5
Ngôn ngữ đánh dấu siêu văn bản dùng để định dạng và xây dựng cấu trúc nội dung trang web.
CSS3
Ngôn ngữ tạo phong cách dùng để thiết kế giao diện và trang trí giao diện người dùng.
Git & GitHub
Hệ thống quản lý phiên bản mã nguồn mở giúp theo dõi lịch sử và làm việc nhóm hiệu quả.

Kỹ năng lập trình

  • HTML5 / CSS3 Semantic
  • JavaScript cơ bản
  • Quản lý mã nguồn với Git & GitHub
  • Thiết kế giao diện Responsive

Lộ trình học tập học kỳ này

  1. Nắm vững HTML5 Semantic, CSS3 và Responsive Web Design.
  2. Thực hành làm các dự án bài tập và tiểu luận nhóm đạt điểm tối đa.
  3. Xây dựng hoàn thiện Website cá nhân và tải mã nguồn lên GitHub Repo.
