# My Website - Trang web cá nhân

Đây là bài thực hành buổi 1 tạo trang web hiển thị về thông tin cá nhân đơn giản bằng ngôn ngữ HTML và CSS

# Tác giả
* **Họ và tên:** Huỳnh Nhật Gia Huy
* **Ngành học:** Công Nghệ Thông Tin

# My Website - Lab 2

Website cá nhân của **Huỳnh Nhật Gia Huy** - Sinh viên ngành Công nghệ thông tin.

## Cấu trúc dự án
- `index.html`: Trang chủ giới thiệu thông tin cá nhân và mục tiêu học tập.
- `about.html`: Trang giới thiệu bản thân và tiểu sử.
- `contact.html`: Trang liên hệ tích hợp Form HTML5 validation hoàn chỉnh.
- `css/style.css`: File định dạng giao diện chung, CSS Reset, Box Model và layout.
- `images/`: Thư mục chứa hình ảnh dự án.

## Kỹ thuật áp dụng
- HTML5 Semantics & Form Validation.
- CSS Reset, CSS Box Model, CSS Specificity.
- Tối ưu SEO Meta tags, Open Graph và Google Font Inter.
